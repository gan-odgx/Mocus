# Mocus — Locus-ийн Монгол хувилбар

iPhone-ийн байршлыг солих үнэгүй, нээлттэй эхийн апп. [ChrisMack32/Locus](https://github.com/ChrisMack32/Locus) дээр суурилсан бөгөөд дараах зүйлс нэмэгдсэн:

- **Монгол интерфейс.** Апп анхнаасаа монголоор нээгдэнэ. Тохиргоо → **Хэл · Language** хэсгээс англи руу сольж болно.
- **Мобайл дата горим.** Wi‑Fi-гүйгээр холбогдож телепорт хийх боломж.
- Газрын зургийн анхны байрлал нь Сүхбаатарын талбай (Улаанбаатар).

## 1.2.2 хувилбарын өөрчлөлт

- **Мобайл дата горимын дараалал зөв боллоо.** iOS хөгжүүлэгчийн туннелийг LocalDevVPN мобайл дата дээгүүр явж байх үед нээхийг хориглодог (iPhone-ийн системийн бүртгэлээр шалгав). Иймээс эхлээд **мобайл датагаа унтрааж** холбогдоно, дараа нь датагаа буцааж асаасан ч телепорт үргэлжлэн ажиллана.
- Дата асаалттай үед «Холбох» дарвал алдаа заахын оронд «Мобайл датагаа одоо унтраана уу» гэж хүлээгээд, дата унтармагц (1 минут хүртэл) өөрөө холбогдоно.
- Шалгах жагсаалт, алдааны мессеж, тохиргооны тайлбарыг шинэ дараалалд тааруулав.

## 1.2.1 хувилбарын өөрчлөлт

- LocalDevVPN асаалттай байхад ч «LocalDevVPN унтраалттай» гэж холбогдохоос татгалздаг алдааг засав. Шалтгаан: LocalDevVPN 1.3 туннелийн хаягаа `10.7.1.1` болгосон тул хуучин шалгалт (`10.7.0.x`) үүнийг танихгүй байсан. Одоо шинэ хаягийг таньдаг бөгөөд шалгалт зөвхөн дэлгэцэн дээрх төлөвт ашиглагдана: анхны Locus шиг үргэлж шууд холбогдохыг оролдож, бүтэлгүйтвэл жинхэнэ шалтгааныг хаалтанд харуулна.
- 1.2-т нэмсэн 5 секундийн хугацааны хязгаарыг авав: эхний холболт удаан байхад тасалдаг байсан.

## 1.2 хувилбарын өөрчлөлт

- Шинэ дүрс (гэрийн тооно = байршлын цэг), шар/улаан өнгө.
- Холбогдох, телепорт хийх үед дэлгэц гацахгүй (5 секундийн хязгаар).
- Холболт тасрахад нэг л мэдэгдэл ирнэ. Дахин холбогдох оролдлого чимээгүй, улам удаан давтамжтай.
- Өөр газар телепорт хийсэн үед шинэ цэг тавибал «Телепорт» болон ■ зогсоох товч хоёулаа гарна.
- Интернэтгүй үед газрын зураг дээр анхааруулга, хадгалсан газрууд руу шууд орох товч гарна.
- Хослуулах файлыг шалгаж байж хүлээн авна. Солихоос өмнө асууна.
- Алдааны мессеж шалтгаанаа хэлж, засах товч санал болгоно.

## Мобайл дата горим (Wi‑Fi-гүйгээр)

Анхны Locus-д эхний телепортыг Wi‑Fi дээр эхлүүлэх шаардлагатай байдаг. iOS хөгжүүлэгчийн туннелийг LocalDevVPN мобайл дата дээгүүр явж байх үед нээхийг хориглодог. Харин сүлжээгүй (мобайл дата унтраалттай) үед зөвшөөрдөг, нээгдсэн туннель дата асаасны дараа ч ажилласаар байдаг.

1. Mocus → **Тохиргоо → Холболтын горим → Мобайл дата**.
2. **Wi‑Fi-гаа унтрааж**, **LocalDevVPN**-ээ асаана.
3. Control Center-ээс **мобайл датагаа унтраана**.
4. Газрын зургийн дээд талын төлөвийн мөр (**Мобайл датаар холбох**) дээр дарж → **Холбох**. Дата асаалттай байсан бол Mocus хүлээж, унтармагц өөрөө холбогдоно.
5. **Мобайл датагаа буцааж асаана**: газрын зураг, хайлт ажиллана.
6. Газрын зураг дээр цэг тавиад → **Телепорт**.

Анхаарах зүйлс:

- **Зогсоох** дарахад туннель хаагдахгүй, тиймээс хүссэн үедээ дахин телепорт хийж болно. Бүрэн салгах бол холболтын цонхны **Салгах** товчийг дарна.
- Холболт тасарвал мобайл датагаа түр унтраагаад **Холбох**-ыг дахин дарна уу. Сүүлд тохируулсан байршил автоматаар сэргэнэ.
- Цонхон дахь ногоон тэмдэглэгээ (Wi‑Fi, мобайл дата) зөвхөн зөвлөмж. iOS нь Control Center-ийн товчлууруудын төлөвийг апп-д шууд өгдөггүй.

## Суулгах

1. IPA файлаа авна (доорх «Mac-гүйгээр бүтээх» хэсгийг үзнэ үү).
2. SideStore, AltStore, Sideloadly, Feather эсвэл LiveContainer-оор суулгана.
3. Хослуулалт:
   - **iOS 27:** Тохиргоо → **Энэ iPhone дээр хослуулах**. Компьютер хэрэггүй.
   - **iOS 18–26:** [idevice_pair](https://github.com/jkcoxson/idevice_pair/releases)-аар **RPPairing** файл үүсгээд апп-д оруулна.
4. App Store-оос [LocalDevVPN](https://apps.apple.com/us/app/localdevvpn/id6755608044) суулгана. Туннелийн үндсэн IP нь `10.7.0.1`.

Bundle ID нь анхных шигээ `com.chrismack.locus` хэвээр байгаа. Тиймээс анхны Locus-ийн дээрээс суулгавал хослуулах файл болон хадгалсан газрууд хэвээр үлдэнэ.

## Mac-гүйгээр бүтээх (GitHub Actions)

iOS апп бүтээхэд macOS хэрэгтэй. GitHub-ийн macOS сервер үүнийг үнэгүй хийж өгнө:

1. Энэ хавтсыг өөрийн GitHub repo руу push хийнэ (жишээ нь ChrisMack32/Locus-ийн fork).
2. Fork дээр **Actions** таб нээгээд workflow-уудыг идэвхжүүлнэ.
3. **Build IPA** workflow push бүрт ажиллана. Мөн гараар **Run workflow** дарж эхлүүлж болно.
4. Ажил дуусмагц **Artifacts** хэсгээс `Mocus-ipa`-г татна (zip дотор `Mocus.ipa` байна).
5. `v1.1.0` гэх мэт tag push хийвэл IPA нь **Releases** хэсэгт шууд хавсаргагдана.

Mac-тай бол: `brew install xcodegen && xcodegen generate`, дараа нь `Locus.xcodeproj`-ийг нээнэ.
